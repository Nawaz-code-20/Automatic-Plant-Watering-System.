# Automatic Plant Watering System

An Arduino-based automatic plant watering system that uses a soil moisture sensor to detect dry soil and automatically turns a water pump ON/OFF through a relay.

## Components Used

- Arduino uno
- Soil Moisture Sensor
- Relay Module
- Water Pump
- Water Pipe
- Connecting Wires
- Power Supply

## How It Works

The soil moisture sensor measures the moisture level of the soil. When the soil becomes dry, the Arduino turns ON the water pump through the relay. When the soil becomes sufficiently wet, the Arduino turns OFF the water pump automatically.

## Features

- Automatic plant watering
- Soil moisture detection
- Automatic water pump control
- Saves water
- Reduces manual effort

## Applications

- Home gardens
- Indoor plants
- Small farms
- Smart irrigation systems

## Project Goal

The goal of this project is to create a simple and automatic irrigation system that provides water to plants when the soil becomes dry.
